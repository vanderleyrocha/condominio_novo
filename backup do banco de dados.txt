FLUXO 2.1 - GERAR BACKUP DO BANCO LOCAL DESTE PC (LARAGON), EXCLUINDO TABELAS GRANDES

Executar no PowerShell local:
mysqldump \
  --host=127.0.0.1 \
  --port=3306 \
  --user=root \
  --single-transaction \
  --quick \
  --routines \
  --triggers \
  --events \
  --hex-blob \
  --default-character-set=utf8mb4 \
  --ignore-table=u815349007_pedemeia2.sgp_lote_linhas \
  --ignore-table=u815349007_pedemeia2.sgp_lote_reversoes \
  --ignore-table=u815349007_pedemeia2.stg_simaed_alunos_matriculas_importacao \
  -p \
  u815349007_pedemeia2 | gzip > "D:\sql\backup_local_u815349007_pedemeia2.sql.gz"

Observacao:
- O comando acima solicita a senha do usuario root local.
- Ajuste o caminho de saida se quiser salvar o arquivo em outra pasta.

1) Enviar o arquivo deste PC para o servidor Hostinger (executar no PowerShell local, fora do SSH):

2) Executar a restauracao dentro do SSH remoto:
gunzip -c ~/backup_pe_de_meia.sql.gz | mysql -u u815349007_pedemeia2 -p u815349007_pedemeia2


ERROS COMUNS

- Rodar comando com caminho D:\... dentro do SSH remoto (isso nao existe no Linux remoto).
- Rodar scp no sentido errado.
  Correto para baixar: origem remota -> destino local.
- Esquecer de usar -p (senha) no mysqldump/mysql.
- Tentar restaurar em banco inexistente no destino.
